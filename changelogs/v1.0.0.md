# Changelog — v1.0.0 (Initial Release)

Initial launch of the premium personal portfolio website **RONN — Digital Playground** built for multimedia creator Rony Imanuel Sihombing.

## Features Added

### Core Framework & Setup
- **Next.js & App Router**: Bootstrapped Next.js with app directory structure and TypeScript support.
- **Tailwind CSS v4**: Set up theme custom variables and colors driving the **Dark Luxury** visual style (`#09090B` background, `#111111` surface, violet, cyan, and success green accents).
- **Lenis Smooth Scroll**: Added global Lenis integration to make page scrolling buttery smooth.
- **SVG Noise Filter**: Implemented an inline SVG fractal turbulence noise overlay covering the viewport.

### Cinematic Interactivity
- **Intro Loader**: Cinematic morph sequence ("RONN" -> "Multimedia" -> "Photography" -> "Design" -> "Development" -> "Creativity") using Framer Motion exit transitions.
- **Google Antigravity Particles**: Built a HTML5 Canvas interactive particle system with custom acceleration physics towards mouse coordinates and floating background blur blobs.
- **Custom Cursor & Lighting**: Added mouse dot tracking, lerped halo, clickable scale indicators, and dynamic CSS properties to drive cursor-based radial lighting gradients.

### Sections & Portals
- **whoami.sh & connect.sh**: Built a reusable glassmorphic UNIX Terminal Emulator for the About and Contact sections supporting typing animations, custom text stdout buffers, and CLI platform navigation redirect commands.
- **Timeline**: Created a responsive timeline illustrating journey milestones with click-to-expand details cards.
- **Featured Works**: Built an asymmetrical Apple-style project card grid with 3D perspective mouse-tilt hooks and modal detail grids.
- **Photography Gallery**: Created an atmospheric photography showcase with parallax image bounds and detailed EXIF lightboxes (Location, Camera model, Shutter speed, Shutter aperture, Year).
- **Skills Orbit Map**: Built a planetary category orbit model utilizing animated pulse-flowing SVG links and detail cards.
- **Experiment Lab**: Implemented entries outlining automated bot developments, Custom ROM builds, and Linux kernel customization research.
- **Meet the Human**: Minimalist card list highlighting Rony's personal philosophies, structured next to a monochrome creative portrait.
