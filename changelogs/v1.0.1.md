# Release v1.0.1

## Bug Fixes

- **Next.js 15 App Router Compatibility**: Replaced `styled-jsx` in `SkillsOrbit.tsx` with a standard React `dangerouslySetInnerHTML` style tag. The `styled-jsx` approach was incompatible with the new Next.js 15 App Router and Turbopack compiler, causing raw HTML tags to render as visible text on production builds.
- **Social Link Correction**: Updated all references to the GitHub profile and other social links across the portfolio. Replaced the incorrect username `ronnsihombing` with the correct one `ronnanakibu` in `Terminal.tsx` and the hero section of `page.tsx`.
- **Bundle Optimization**: Removed an unused `AnimatePresence` import from `page.tsx` to prevent unnecessary bundle bloat.
