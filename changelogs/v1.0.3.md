# Release v1.0.3

## Bug Fixes

- **Font Fallback Syntax**: Fixed an issue in `globals.css` where `var(--font-space-grotesk, sans-serif)` did not trigger the fallback correctly when the Next.js font string was injected but the font asset failed to load. Adjusted to `var(--font-space-grotesk), sans-serif` to guarantee a true CSS fallback to modern sans-serif instead of the browser default serif.
- **Terminal Languages**: Added the missing requested languages (JS, C++, Python, Java, HTML/CSS) to the output of the `skills` command inside the interactive terminal component.
