# Release v1.0.2

## Bug Fixes & Refinements

- **Global Font Fix**: Resolved a critical issue where the entire site was falling back to the browser's default serif font (Times New Roman), causing a broken "unstyled HTML" appearance. The Next.js `next/font` variables for `Space Grotesk` and `Space Mono` were previously attached to the `<body>` element, making them inaccessible to the `<html>` root font declaration in Tailwind v4. Moved the variables to the `<html>` tag and added explicit `sans-serif` and `monospace` fallbacks in `globals.css`.
- **Portrait Aspect Ratio**: Fixed the `rony-portrait-headshot.png` container dimensions in the `Meet the Human` section. The container was previously set to a rectangular `h-[400px]` which caused the square source image to zoom in excessively and crop awkwardly when `object-cover` was applied. Changed to a proportional `300x300` container.
- **Card Proportions**: Increased the minimum height of the Featured Work cards from `300px` to `380px` to prevent them from looking flattened ("gepeng") on wide desktop screens.
- **Added Missing Languages**: Added `JavaScript`, `C++`, `Python`, `Java`, and `HTML/CSS` into the "Development" category of the `SkillsOrbit` visualization as requested.
