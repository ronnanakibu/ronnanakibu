# v2.0.0 - The Digital Playground Release

**Date:** 2026-06-05

## Overview
Major release overhauling the entire RONN Portfolio into a high-end, immersive, and cinematic digital playground, heavily focused on storytelling, smooth interactions, and 3D visual environments.

## Major Features
- **Cinematic Entry:** Replaced the loading screen with a pure cinematic morphing sequence leading to an opacity fade-out.
- **Three.js Environment:** Added a responsive 3D particle background system and energy field powered by `@react-three/fiber` and `@react-three/drei`.
- **Dynamic Scroll Timeline:** Completely rewrote the Creative Journey timeline to trace vertically with a line that grows natively based on scroll position and triggers illuminating nodes.
- **Hero Redesign:** Updated the landing section to feature a deep, asymmetrical layout combining massive typography and an interactive parallax glassmorphic visual pane.
- **Storytelling Deep-Dive:** Upgraded the 'Meet the Human' section into an emotional, monochrome aesthetic with slow, spaced-out typographic reveals.
- **Micro-animations:** Added global custom spring-physics cursor with glowing active states and hover physics across cards and buttons.

## Technical Upgrades
- Added `Inter` and `JetBrains Mono` variable fonts directly via Next.js Google Fonts optimization.
- Switched layout transitions to use complex GSAP and Framer Motion orchestrations.
- Integrated `Lenis` globally for momentum-based smooth scrolling logic.
