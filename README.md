## 🛠️ Build and Deploy Locally

To run this interactive digital portfolio locally:

```bash
# Clone the repository
git clone https://github.com/ronnanakibu/ronnanakibu.git

# Enter workspace
cd ronnanakibu

# Install modules
npm install

# Run dev environment
npm run dev
```
